# 需求文档：能力地图 & 规划仪表盘

**需求方**: 龙虾合伙人（ceo-agent）
**日期**: 2026-05-08
**状态**: 待开发
**优先级**: 高

---

## 1. 背景和目的

### 1.1 问题
- 老板有 43 个 Agent、大量 Skills、多条业务线，但没有一个地方能**一眼看清全貌**
- 每次讨论规划和能力状态，都需要重新扫描所有 workspace，浪费时间和 token
- 能力状态、Agent 状态、规划目标散落在各处，无法维护和迭代

### 1.2 目标
在 LLM Todo 平台中新增**「能力地图」**模块，作为龙虾生态的全景记录器和规划仪表盘。

**核心价值**：
- 人类可读、分层结构的能力全景
- 可在上面讨论、更正、迭代
- 规划目标从抽象（5年愿景）到具体（本周待办）贯通
- 数据持久化，不用每次重新扫描

---

## 2. 功能需求

### 2.1 数据模型：能力域（Capability Domain）

在现有 `tasks.json` 之外，新增一个数据文件 `data/capabilities.json`：

```json
{
  "domains": [
    {
      "id": "writing",
      "name": "✍️ 写作",
      "maturity": 3,           // 1-5 星
      "description": "技术博客、文学创作、文风学习",
      "agents": ["blog-agent", "creative-writer", "writing-style-analyst-agent"],
      "skills": ["tts-skill"],
      "subCapabilities": [
        {
          "id": "tech-blog",
          "name": "技术博客写作",
          "status": "available",   // available | building | planned | gap
          "notes": "blog-agent 每日自动写作"
        },
        {
          "id": "style-learning",
          "name": "文风学习",
          "status": "building",
          "notes": "笔探在分析历史文章"
        }
      ],
      "gaps": ["写作→审稿→发布的自动化闭环未完全跑通"],
      "updated": "2026-05-08"
    }
  ]
}
```

### 2.2 数据模型：Agent 状态（Agent Status）

新增 `data/agents.json`：

```json
{
  "agents": [
    {
      "id": "stock-agent",
      "name": "股票分析师",
      "category": "投资",
      "status": "active",          // active | idle | disabled
      "cronActive": false,
      "lastActive": "2026-05-08T07:20:00+08:00",
      "capabilities": ["价值投资分析", "量化数据管道"],
      "relatedDomain": "stock",
      "notes": "之前每日推送停了，异常驱动模式未实现"
    }
  ]
}
```

### 2.3 数据模型：规划目标（Roadmap）

在现有 `todo/horizons/` 基础上，新增结构化的规划数据 `data/roadmap.json`：

```json

      "period": "3个月",
      "deadline": "2026-08-08",
      "items": [

          "id": "m-2026-q3-1",
```

### 2.5 API 端点

新增以下 API：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/capabilities` | 获取所有能力域 |
| GET | `/api/capabilities/:id` | 获取单个能力域详情 |
| PUT | `/api/capabilities/:id` | 更新能力域 |
| GET | `/api/agents-status` | 获取所有 Agent 状态 |
| PUT | `/api/agents-status/:id` | 更新 Agent 状态 |
| GET | `/api/roadmap` | 获取规划路线图 |
| PUT | `/api/roadmap` | 更新规划路线图 |

### 2.6 Chat 集成

通过 LLM Todo 的聊天入口，支持自然语言更新：

- "把写作能力的成熟度调到4"
- "新增一个视频能力域"
- "把 stock-agent 的状态改为 active"
- "3个月目标里加一条：视频流程建立"

## 6. 验收标准

1. 打开 `/map` 能看到所有能力域的卡片网格
2. 点击某个能力域能展开看到子能力状态和 Gap
3. 能看到规划仪表盘（3月/6月/1年目标及进度）
4. API 能正常读写 capabilities/agents/roadmap 数据
5. 数据更新后页面刷新可见
