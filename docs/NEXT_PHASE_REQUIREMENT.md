## 1. 角色页面改造（/character）

### 1.1 问题
当前角色页面是 RPG 游戏风格（智力、体力、敏捷等属性），对实际使用没有帮助。

### 1.2 需求
保留游戏化的**技能树**视觉风格，但把能力替换为**真实的实用能力**：

#### 能力类别（参考）
每个能力是一个具体的、可衡量的实用技能，例如：

| 能力 ID | 名称 | 图标 | 描述 | 等级来源 |
|---------|------|------|------|---------|
| shopping | 购物助手 | 🛒 | 淘宝/京东比价、购物清单管理、自动下单 | 已完成的购物任务数 |
| voice | 语音能力 | 🔊 | TTS 语音合成、语音消息发送、播客制作 | 语音消息发送次数 |
| writing | 写作能力 | ✍️ | 技术博客、文学创作、文风学习 | 已发布的文章数 |
| publishing | 发布能力 | 📤 | 多平台发布（飞书、博客、社交媒体） | 已发布的内容数 |
| research | 深度研究 | 🔍 | 多源研究、报告生成、信息整合 | 完成的研究报告数 |
| coding | 编程能力 | 💻 | 代码生成、项目开发、Bug 修复 | 完成的开发任务数 |
| scheduling | 日程管理 | 📅 | 日历管理、提醒推送、时间规划 | 管理的事件数 |
| finance | 投资理财 | 📈 | 股票分析、量化策略、财务追踪 | 分析报告数 |
| translation | 翻译能力 | 🌐 | 多语言翻译、文档本地化 | 翻译次数 |
| task-management | 任务管理 | ✅ | 任务追踪、优先级排序、进度监控 | 管理的任务数 |

#### 视觉设计
- **技能树布局**：像游戏天赋树一样，能力之间有连线（如 writing → publishing 是一条路径）
- **等级展示**：每个能力有 1-5 星，根据实际使用数据计算
- **头像区域**：角色头像（可以是像素风或手绘风 2D 图标）
- **核心能力标签**：当前最突出的 3-5 个能力，醒目展示
- **任务关联**：每个能力可以展开看到关联的任务列表

### 1.3 数据结构
扩展现有 `data/capabilities.json`，每个能力域增加：
```json
{
  "id": "shopping",
  "name": "🛒 购物助手",
  "level": 2,
  "maxLevel": 5,
  "xp": 15,
  "xpToNext": 30,
  "relatedTasks": ["task-xxx"],
  "unlockedAt": "2026-05-08",
  "skills": ["比价", "购物清单", "自动下单"]
}
```

## 2. 首页 Tab 化重构

### 2.1 问题
当前首页把任务列表 + 规划文档 + 聊天窗口全挤在一个页面，信息过载，无法聚焦。

### 2.2 需求
拆分成独立 Tab 页面：

```
┌──────────────────────────────────────────────┐
│  LLM Todo                                    │
│  [📋 任务]  [🗺️ 规划]  [💬 聊天]  [🧭 能力地图] [👤 角色] │
└──────────────────────────────────────────────┘
```

#### Tab 1: 📋 任务（由效率管家负责）
- 任务列表，按优先级分层展示（见第 3 节）
- 快速新增任务
- 筛选和搜索

#### Tab 2: 🗺️ 规划（由龙虾合伙人负责）
- 长期规划文档（horizons: lifetime → decade → year → quarter → month → week → today）
- 规划仪表盘（目标进度可视化）
- 能力域卡片 + Agent 状态
- 合并现有 /map 页面内容

#### Tab 3: 💬 聊天
- 现有聊天入口独立成页
- 三种模式不变（本地规则助手 / OpenAI Responses / Agent Chat）

#### Tab 4: 🧭 能力地图（保留 /map 路径）
- 能力域卡片网格
- 规划路线图
- Agent 状态

#### Tab 5: 👤 角色
- 改造后的角色页面

### 2.3 技术要点
- 使用前端 Tab 切换（单页应用），不需要多页面跳转
- 或者使用现有的多页面结构，统一导航栏
- 导航栏在所有页面共享，高亮当前所在 Tab

## 3. 任务列表分层展示

### 3.1 问题
当前任务列表是平铺的，看不出轻重缓急，不知道从哪里下手。

### 3.2 需求
任务默认按优先级分组展示，不是平铺列表：

```
┌─────────────────────────────────────────┐
│  🔴 现在就做 (3)                          │
│  ├── ✅ 完成 LLM Todo 原型     📅 明天到期  │
│  ├── 🔧 接入 LLM provider      📅 本周    │
│  └── 🛠️ 能力地图模块开发        📅 5/16    │
├─────────────────────────────────────────┤
│  🟡 本周待办 (4)                          │
│  ├── 📦 Todoist 数据迁移                  │
│  ├── 🔔 定时任务/提醒推送                  │
│  └── ...                                │
├─────────────────────────────────────────┤
│  ⚪ 未来 / 待定 (5)                        │
│  ├── 📚 搭建 LLM Wiki          📅 季度    │
│  ├── 🎙️ 播客/语音内容启动       📅 季度    │
│  ├── 📱 提交 iOS 应用           📅 季度    │
│  └── ...                                │
└─────────────────────────────────────────┘
```

#### 分组规则
1. **🔴 现在就做**：满足任一条件
   - 今日到期（due ≤ 今天）
   - 已过期（due < 今天）
   - priority = "high" 且 horizon = "week" 或更短

2. **🟡 本周待办**：满足任一条件
   - 本周内到期
   - priority = "medium" 且有明确 nextAction
   - priority = "high" 但 horizon 较长

3. **⚪ 未来 / 待定**：
   - horizon ≥ "month" 且无近期 deadline
   - priority = "low"
   - 无 nextAction

#### 交互
- 每个分组可折叠/展开
- 分组标题显示任务数量
- 任务卡片上显示：标题、截止日期、优先级标记、标签
- 支持拖拽调整优先级（v2，可选）
