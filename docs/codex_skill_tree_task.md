## 需要做的改动

### 1. 后端：重写技能树数据模型（P0）

替换 `PRACTICAL_ABILITIES` 为 `SKILL_TREES`，严格按照 SKILL_TREE_DESIGN.md 的 5 大主线：

```
主干一：内容创作线（文本写作→多平台发布/语音/图像/视频）
主干二：投资理财线（投资研究→量化交易）
主干三：系统工具线（个人操作系统→任务管理/知识库/Agent工作台/Agent调度）
主干四：生活服务线（生活→健康/购物/旅游/育儿/3D打印/报销）
主干五：运营/增长线（运营与增长→KPI面板/增长技能/分析技能）
```

每个技能节点必须包含：
- `id`: 唯一标识
- `name`: 显示名称（含 emoji）
- `level`: 当前等级（0-5），严格按照文档中的等级评估
- `maxLevel`: 5
- `parentId`: 父节点 id（顶级为 null）
- `treeId`: 所属主线 id（content-creation / investment / system-tools / life / growth）
- `dependencies[]`: 前置依赖技能 id 列表
- `upgradeConditions[]`: 升级条件描述列表
- `status`: "locked" | "beginner" | "usable" | "proficient" | "expert" | "master"
- `lastVerified`: 上次验证日期
- `notes`: 状态说明（如"有持续产出，但频率不稳定"）

新增 `skill_trees_payload()` API 返回完整的技能树数据：
```json
{
  "trees": [
    {
      "id": "content-creation",
      "name": "🌿 内容创作线",
      "rootId": "text-writing",
      "nodes": [...]
    },
    ...
  ]
}
```

### 2. 后端：等级颜色映射（P0）

按照文档第 3 节：
- Lv.0 → 🔒 灰色 (gray)
- Lv.1 → 🌱 浅蓝 (lightblue)
- Lv.2 → 🔄 蓝色 (blue)
- Lv.3 → ✅ 绿色 (green)
- Lv.4 → ⭐ 金色 (gold)
- Lv.5 → 🏆 紫色 (purple)

### 3. 前端：技能树可视化（P0）

重写 `web/character.js` 和 `web/character.html` 中的能力展示部分：

- **5 个 Tab** 切换 5 条技能主线（内容创作/投资理财/系统工具/生活/运营增长）
- 每条线展示为**树形布局**，节点之间用 SVG 连线表示依赖关系
- 节点样式根据等级显示不同颜色（参考暗黑破坏神技能树风格）
- **Lv.0 节点显示为灰色锁定状态**，但可见（让人知道还有路可走）
- **点击节点**展开详情面板：
  - 当前等级 + 等级名称
  - 状态说明（notes）
  - 升级条件列表（upgradeConditions）
  - 关联任务（如有）
  - 上次验证日期

### 4. 前端：KPI 面板占位（P1）

在技能树页面顶部显示 KPI 面板框架（数据可以先硬编码为 "数据未采集"）：
- 📊 粉丝数（各平台）
- 📈 近期内容产出量
- 💰 收入（投资/内容/工具）
- ⏱️ 时间投资回报率

### 5. API 路由

新增或修改：
- `GET /api/skill-trees` → 返回完整技能树数据
- `GET /api/character` → 保留现有角色数据，但 abilities 替换为技能树摘要
